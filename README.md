# Omani Seaweed Database: mobile app demonstration

Mobile web app for the HMTF 2027 proposal (priority 3.1.9, Omani biota database), using the genus *Laurencia* as the example. It opens in the phone's browser from a link or QR code; nothing is installed.

- **Content:** the same real data as the database websites: 43 Omani herbarium records from GBIF (accessed 6 November 2026), the SQU voucher SW-R1 (Elaswad et al. 2026, *Phycology* 6: 90), DNA barcodes from GenBank and unpublished SQU data, and photographs (SW-R1, CC BY; AlgaeBase reference photos for demonstration only).
- **Languages:** English and Arabic.
- **Field records:** the "Record" tab takes photos with the phone camera, reads the GPS position, and saves the record on that phone only, marked "pending review". Nothing is sent anywhere.
- **Assistant:** a built-in chat panel that answers from the same data, in the browser.

Database websites: `../laurencia-demo-bilingual/` (English / Arabic) and `../laurencia-demo/` (detailed, English).
